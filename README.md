# Moodle AI Assistant

Локальний проєкт AI-асистента для Moodle. Розробка йде поетапно: на першому
етапі створено базовий REST API на FastAPI. Інтеграції з AI та Moodle, база
даних, Docker і браузерне розширення поки не підключені.

## Поточна структура

```text
backend/
  app/          FastAPI-застосунок і Pydantic-схеми
  tests/        API-тести на Pytest і HTTPX
  requirements.txt
  README.md     Інструкції запуску backend
extension/     Папка для майбутнього браузерного розширення
```

## Запуск API

Потрібен Python 3.13. Інструкції для Windows PowerShell наведено у
[backend/README.md](backend/README.md).

## Поточні маршрути API

- `GET /health` — перевірка доступності сервера.
- `POST /api/answer` — приймає питання та варіанти й повертає повідомлення, що
  AI ще не підключений. Сервіс не вгадує відповідь.

## Тести

З папки `backend` після встановлення залежностей:

```powershell
python -m pytest
```

## Налаштування Git

Файл `.gitignore` виключає локальне віртуальне середовище, кеші, IDE-файли,
секрети та згенеровані артефакти. Шаблони `.env.example` дозволено додавати до
Git, але реальні `.env` файли з секретами — ні.
