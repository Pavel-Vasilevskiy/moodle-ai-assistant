# Backend API

Інструкції встановлення, налаштування OpenAI, запуску FastAPI, Swagger UI та
Pytest зібрані в кореневому [README.md](../README.md).

Запуск сервера виконується з цієї папки:

```powershell
python -m uvicorn app.main:app
```

Для збереження результатів завершеної спроби API також має локальний
`POST /api/quiz-import`. Endpoint приймає лише структурований JSON із розширення,
не HTML. Дані зберігаються в таблицях `quiz_imports` та
`quiz_import_questions` тієї самої SQLite-бази, окремо від кешу AI-відповідей і
токен-статистики. На диску можуть лишитися тексти запитань, варіантів і вибору;
базу не синхронізовано й не очищується автоматично.
